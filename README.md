# Modus Mobile PWA

Aplicación Web Progresiva (PWA) para clientes y técnicos aliados de **Modus Mobile** (Disciplina ATDM - Administración Técnica de Dispositivos Móviles).

## Características
- Ficha técnica de estado e intervención del dispositivo móvil.
- Semáforo y contador de garantía operativa con cláusulas legales.
- Funcionamiento offline autónomo mediante Service Worker.
- Consulta dinámica y segura contra base de datos Supabase (RLS).

## Tecnologías
- **Frontend:** HTML5, CSS3 (tema oscuro ATDM), Vanilla JavaScript.
- **Despliegue:** GitHub Pages (HTTPS global).
- **Base de Datos:** Supabase (PostgreSQL serverless).
